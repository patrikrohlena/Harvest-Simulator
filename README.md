# Harvest Simulator

Harvest Simulator je hra zaměřená na sbírání předmětů, vydělávání peněz a postupné vylepšování vybavení. Hráč sbírá různé předměty, například dýně, pomocí nástrojů, jako jsou lopaty. Za nasbírané předměty získává peníze, které může využít k nákupu lepších nástrojů a odemykání nových úrovní.

Hra je vyvíjena v herním enginu **Unreal Engine 5**.

## Hlavní herní mechaniky

* **Sbírání předmětů:** Hráč sbírá různé předměty a suroviny pomocí dostupných nástrojů.
* **Vydělávání peněz:** Za nasbírané předměty získává peníze, které může dále investovat do svého vybavení.
* **Vylepšování nástrojů:** Lepší nástroje umožňují sbírat předměty rychleji a efektivněji.
* **Odemykání nových úrovní:** Postupem ve hře si hráč odemyká další oblasti s novými a hodnotnějšími předměty.
* **Postupný rozvoj:** Každá nová úroveň přináší lepší možnosti výdělku a umožňuje hráči dále vylepšovat své vybavení.

## Cíl hry

Cílem je vydělávat co nejvíce peněz, pořizovat si stále lepší nástroje a postupně odemykat nové úrovně, ve kterých lze sbírat hodnotnější předměty efektivněji.
